# HyeTraq demo script

Use this script only for the functionality that is actually implemented. Do not imply that a plan preview is a completed research run or a paid transaction.

## Current scaffold demo (about 90 seconds)

1. Open the HyeTraq workspace.
2. Enter a concrete Celo/Web3 research question and set a small cap.
3. Click **Build research plan**. Explain that this returns a plan, not a final report.
4. Click **Check live catalogue**. If it succeeds, show the returned live-check timestamp and explain that catalogue discovery does not prove a service was purchased.
5. Show the payment-status panel and explain that paid execution is disabled and no payment was attempted in this scaffold.
6. Close with the next milestone: verified quote, user approval, paid call, settlement evidence, and evidence-linked report.
